How to convert an equirectangular panorama to a cubemap

  1. Choose a complete sphere. Use a 2:1 PNG, JPEG or WebP panorama, such as 2048 × 1024 or 4096 × 2048. A cropped photograph or a stretched flat image will not become a full 360° scene.
  2. Try a sample or open your image. Compare the source above with the six-face preview. The front view comes from the center of the source panorama; the back view crosses its left/right seam.
  3. Select 256, 512 or 1024 px per face. Start at 512 for a quick check. Larger output cannot recover detail missing from the original.
  4. Download all six faces as a ZIP. Extract the archive before assigning the PNGs to skybox slots. Individual face downloads use a cubemap- filename prefix; ZIP entries use the names in the table below.

Need help checking your source? Read the equirectangular projection guide. For a Radiance .hdr source, use the HDRI to cubemap converter.

Use your cubemap in Unity, Three.js or Unreal Engine

Unity: six PNG faces with Skybox / 6 Sided

  1. Extract the ZIP into your Assets folder. Select the six textures and set Wrap Mode to Clamp to avoid repeating the opposite edge.
  2. Create a Material with the Skybox / 6 Sided shader. Assign each PNG using the axis table above.
  3. Assign that material as the scene Skybox Material in the Lighting environment settings. Check the horizon and top/bottom faces in the scene.

This shader works with Built-in and URP, not HDRP. See Unity’s 6 Sided skybox reference for pipeline compatibility.

Three.js: load faces in axis order

Place the extracted PNGs in one public folder and pass URLs in +X, −X, +Y, −Y, +Z, −Z order to CubeTextureLoader. Three.js uses a different handedness convention for cube backgrounds, so check left/right landmarks against the source panorama. See the CubeTextureLoader reference before adjusting orientation.

Unreal Engine: retain the original HDR environment

The ZIP contains six ordinary PNG textures, not an Unreal TextureCube asset. For an HDRI Backdrop, enable the HDRI Backdrop plugin, import a supported .hdr environment, add an HDRI Backdrop actor, and select the imported cubemap in its Cubemap property. The PNG ZIP is not a direct substitute.

Follow Epic’s HDRI Backdrop setup. Exported PNGs do not preserve HDR radiance for lighting.

Fix seams, rotated faces and blurry cubemaps

A seam appears behind the camera
Inspect the source’s left and right edges in the 360 panorama viewer. Slicing cannot repair a mismatched source seam. If only the engine shows an edge line, check Clamp wrapping, filtering and mipmaps.
The sky is upside down or faces are swapped
Use the filename-to-axis table rather than alphabetical file order. Compare a recognizable landmark and the horizon; engine conventions can differ in handedness and face rotation.
The output looks blurry or stretched
Start with a complete, sharp 2:1 panorama. Increasing face resolution cannot restore missing detail. A normal flat photo or a cropped panorama is not a complete sphere, even if resized to 2:1.
PNG faces do not light the scene like the HDR original
These are display images. Use the original scene-linear HDR file for lighting; see HDRI versus LDR environment lighting. To rebuild a 2:1 display panorama from faces, use the cubemap to equirectangular converter.

Cubemap Slicer Questions & Answers

What does this panorama to cubemap converter export?

It reprojects a full 2:1 equirectangular panorama into six square PNG images, each covering a 90° view. The ZIP contains posx, negx, posy, negy, posz and negz faces. These are display images for a visible skybox, not floating-point HDR lighting maps or a DDS cubemap file.

Are files uploaded to a remote server during cubemap slicing?

No. Cubemap slicing runs locally using HTML5 Canvas. Selecting a local image or a sample does not upload it to a server. AI panorama generation is a separate online feature.

What face resolutions are supported for ZIP download?

You can choose between 256x256, 512x512, or 1024x1024 pixels per cube face. Clicking "Download All (ZIP)" packages all 6 faces into a single compressed archive with the filenames listed in the orientation table below.

How are the cube faces named in the downloaded ZIP?

The archive contains posx.png (Right), negx.png (Left), posy.png (Top / Up), negy.png (Bottom / Down), posz.png (Front), and negz.png (Back). Assign files by axis using the table below, then check orientation in your target engine; filenames alone do not determine face rotation.

Can I convert an HDR or EXR file here?

This slicer opens browser-readable PNG, JPEG and WebP panoramas. For a Radiance .hdr file, use the HDRI viewer linked below; its PNG cube exports are tone-mapped display images. OpenEXR is not supported. Keep your original HDR file for environment lighting.

Can I download free cubemaps directly without uploading?

Yes! Click any of the free presets (Cosmic Nebula, Cyberpunk Metropolis, Tropical Sunset, etc.) above the slicer to instantly preview the 6 sliced faces and click "Download All (ZIP)" to get a free cubemap pack immediately.
