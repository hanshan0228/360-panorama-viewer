Häufig gestellte Fragen

Werden meine Bilder auf einen Server geladen?

Nein. Das Rendering läuft vollständig clientseitig im WebGL-Speicher Ihres Browsers.

Unterstützt der Viewer das Einfügen per Zwischenablage?

Ja! Drücken Sie einfach Strg+V (Cmd+V auf Mac), um ein kopiertes Panorama direkt anzuzeigen.
