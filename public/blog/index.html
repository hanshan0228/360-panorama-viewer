Keep projection and dynamic range separate

A 2:1 rectangle describes the usual full-sphere layout. A .hdr extension describes a file container. Neither guarantees a complete, correctly captured HDR environment. The guides explain how to check source coverage, lighting values, metadata and orientation before sending a file to another app.
