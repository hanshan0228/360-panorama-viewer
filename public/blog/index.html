Keep projection and dynamic range separate

A 2:1 rectangle describes the usual full-sphere layout. A .hdr extension describes a file container. Neither guarantees a complete, correctly captured HDR environment. The guides explain how to check source coverage, lighting values, metadata and orientation before sending a file to another app.

360° Panorama Fundamentals: Formats & Workflows

A true spherical panorama covers a 360-degree horizontal field of view and a 180-degree vertical field of view, creating a complete environment sphere without blind spots. When stored as a flat image, this sphere is mapped using an equirectangular projection with a strict 2:1 width-to-height aspect ratio (such as 4096×2048, 8192×4096, or 16384×8192 pixels). The top horizontal edge corresponds to the zenith (sky straight up), the bottom edge corresponds to the nadir (ground straight down), and the left and right edges meet seamlessly behind the viewer.

Standard 8-bit image formats like JPEG, PNG, and WebP encode Low Dynamic Range (LDR) color suitable for direct display on computer screens and mobile browsers. In contrast, 32-bit formats like Radiance RGBE (.hdr) and OpenEXR (.exr) encode High Dynamic Range (HDRI) floating-point luminance values, allowing 3D rendering engines like Blender Cycles, Unreal Engine 5, and Unity to simulate authentic sun glare, realistic shadows, and accurate ambient reflections.

Why did my 360° photo upload as a flat, distorted rectangle on Facebook?

Social media platforms like Facebook and Google Street View require specific Google PhotoSphere XMP metadata embedded in the JPEG header to recognize an image as an interactive 360-degree sphere. If this metadata is stripped during export from an image editor or messaging app, the platform treats it as an ordinary 2D photo. Use our free 360 Metadata Injector to restore the missing GPano XMP tags with one click.

Can 360° equirectangular panoramas be converted into 6-sided cubemaps?

Yes. Game developers and 3D artists frequently slice 2:1 spherical panoramas into six rectilinear cube faces (+X, -X, +Y, -Y, +Z, -Z) to use as skyboxes in Unity, Unreal Engine, Godot, or custom Three.js scenes.
